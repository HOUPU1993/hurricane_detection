When testing a new specification, add one row here and change the corresponding values in `PARAMETERS.sql` before running it in Snowflake.

Note: the `Preprocessing` column only matters for specifications that predate `03_overlapping_time_union.sql` (i.e. `main_v1`). All specifications from `main_v2` onward run on the unioned/trimmed stop table; a new row only needs to repeat "Post-union: ..." if it reverts to the old preprocessing for a sensitivity check.
